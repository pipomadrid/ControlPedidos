Proyecto personal. Aplicación de escritorio para procesar y resumir pedidos a partir de archivos Excel, desarrollada en Java 21 y JavaFX 21.


![Uploading image.png…]()


🚀 Funcionalidades principales

✅ Cargar múltiples archivos Excel con información de pedidos y clientes.

✅ Cruzar datos automáticamente para detectar coincidencias, duplicados o faltantes.

✅ Generar resumen de pedidos en un archivo Excel consolidado listo para análisis o envío.

✅ Interfaz intuitiva con JavaFX para seleccionar archivos y exportar resultados.

✅ Soporte para distintos formatos de Excel (.xlsx, .xls).

✅ Rápido y confiable, incluso con grandes volúmenes de datos.

🛠 Tecnologías usadas

Java 21

JavaFX 21

Maven como gestor de dependencias

Apache POI para lectura y escritura de archivos Excel

Plugins Maven:

maven-assembly-plugin → JAR con dependencias

javafx-maven-plugin → ejecutar la app con JavaFX

jpackage-maven-plugin → generar ejecutables .exe o .pkg
